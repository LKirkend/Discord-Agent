# Antigravity Discord Liaison Bot

A centralized, interactive Discord bot and API daemon designed to act as an approval liaison, dashboard monitor, and message routing hub for Google Antigravity SDK agents.

**Long-Term Goal:** A standalone Discord bot that can act as a liaison to AI models requesting permissions or requiring user input, serving that data from Discord DM chats & servers. Compatible with Antigravity-IDE and Antigravity 2, but aiming to be an agent compatible with any model that acts as a user message delivery and translation layer. Aiming for odysseus support soon.

## 🚀 Key Features

1. **Centralized Approval Management**:
   - Spawns a local REST server (defaulting to port `18000`) that processes `/approve` hooks.
   - Any agent running on the machine can make requests here and prompt the user on Discord with **Approve ✅** and **Deny ❌** buttons.
2. **Interactive Live System Dashboard**:
   - Sent directly to the user's Discord DM.
   - Automatically tracks system shell processes (active training runs) with numbered emoji listings.
   - Monitors active and idle agent sessions across all workspace folders, showing goal names and last active indicators.
   - Includes custom, role-playing person emojis representing the agent types (🕵️ for research, 🧑‍💻 for developer, 🤖 for model training, etc.).
3. **Remote Process and Messaging Controls**:
   - Click on any agent button in the dashboard to review their active tasks, logs, and `task.md` checklist.
   - Includes **Send Message 💬** to send direct DMs to the agent via a Discord TextInput Modal.
   - Includes **Stop Active Task 🛑** to kill running tasks (processes) remotely.
4. **Bi-directional Conversations**:
   - Direct text messages sent to your DM with the bot are automatically routed to the messages queue of the most recently active agent session.
   - A background loop (`transcript_monitor`) polls the active agent's transcript (`transcript.jsonl`) every 2 seconds, auto-forwarding any text response generated by the model back to your Discord DM, including tool call summaries.

## 🛠️ Environment Configuration

Create a `.env` file in the root of the workspace directory based on `.env.example`:

```env
DISCORD_BOT_TOKEN=your_token_here
DISCORD_CLIENT_ID=your_client_id_here
DISCORD_CLIENT_SECRET=your_client_secret_here
DISCORD_CHANNEL_ID=
DISCORD_USER_ID=your_discord_user_id_for_approvals
DISCORD_USER_NAME=your_discord_username_for_autoregistration
PORT=18001
```

### Path Configurations (Optional)
If running outside default paths, you can override them via environment variables:
* `ANTIGRAVITY_BRAIN_DIR`: Directory where Antigravity stores agent session folders (defaults to `~/.gemini/antigravity/brain`).
* `ENV_FILE_PATH`: Location of the `.env` file to persist the auto-discovered Discord User ID (defaults to the local `.env` file).
* `OPEN_FEEDBACK_REMOVER_DIR`: Target path for files modifications checks (defaults to `~/OpenFeedbackRemover`).

## 📦 Installation & Setup

1. **Discord Portal Setup**:
   - Go to [Discord Developer Portal](https://discord.com/developers/applications) and create a New Application.
   - Go to **Bot** -> Enable **Message Content Intent** (Required for standard commands).
   - Go to **OAuth2** -> **URL Generator** -> Check `bot` and `applications.commands`. Under bot permissions, configure/set the permissions integer to `8471182706732241` (which includes Send Messages, View Channels, Manage Messages, Read Message History, Use External Emojis, Add Reactions, etc.).
   - Add the bot to your target server using the generated URL.

2. **Daemon Installation**:
   
   #### Option A: Automated Installation (Recommended)
   Run the dedicated installer in the root workspace folder to provision files, setup the `.venv`, register a launch agent (macOS auto-startup), and link the plugin.
   * **macOS/Linux**:
     ```bash
     ./install_agy2.sh
     ```
   * **Windows**:
     ```cmd
     install_agy2.bat
     ```

   #### Option B: Manual Setup
   Set up a virtual environment and install the required dependencies:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

3. **Running the Bot Daemon**:
   - Launch the daemon concurrently running the FastAPI server and Discord loop:
     ```bash
     python3 -u bot.py
     ```

## 🔧 Incorporating Into Agents

To configure any Antigravity agent to route its write/exec confirmations through this Discord manager:

```python
from google.antigravity import Agent, LocalAgentConfig
from discord_policy import get_discord_policies

config = LocalAgentConfig(
    policies=get_discord_policies()
)

async with Agent(config) as agent:
    # Any write command executed inside this block will prompt you on Discord
    await agent.chat("Let's list files.")
```

## 🏁 Bot Commands

In your Discord DM chat with the bot, you can run the following commands:
* `!status`: Fetches system-wide active training processes and outputs the last 15 lines of the latest modified task log.
* `!updates`: Lists recently modified files in the target project folder over the last 2 hours.
* `!commands`: Displays the help menu listing available commands.
